# Closed Traverse Adjustment – HTML Version

เว็บแอปคำนวณและปรับแก้วงรอบปิดสำหรับเผยแพร่บน GitHub Pages

## ไฟล์

- `index.html`
- `styles.css`
- `app.js`

## วิธีเปิดในเครื่อง

ดับเบิลคลิก `index.html`

## วิธีเผยแพร่ GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลด `index.html`, `styles.css`, `app.js`
3. เข้า `Settings`
4. เลือก `Pages`
5. Source เลือก `Deploy from a branch`
6. Branch เลือก `main` และโฟลเดอร์ `/root`
7. กด `Save`

จากนั้น GitHub จะสร้างลิงก์ออนไลน์รูปแบบ:

`https://username.github.io/repository-name/`

## ความสามารถ

- Compass Rule และ Transit Rule
- คำนวณ Azimuth A–O และ A–B
- เพิ่มและลดหมุด
- ตรวจสอบค่าคลาดปิดมุม C√N
- ตรวจสอบ Error of Closure 1 : x
- คำนวณพิกัดก่อนและหลังปรับแก้
- คำนวณพื้นที่ภายในวงรอบหลังปรับแก้
- ดาวน์โหลด CSV, Excel และ PDF
- พิมพ์รายงานหรือ Save as PDF

- แสดงค่าพิกัด ระยะด้าน และมุมผูกบนรูปวงรอบ

- แสดงค่าพิกัดตามแกน Easting และ Northing รอบรูปวงรอบ
